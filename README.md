# GKG 全球新闻语义分析与主题追踪平台

基于 GDELT 2.0 GKG 数据的桌面分析系统。支持新闻批量导入、人物/组织/主题查询、共现网络可视化（PageRank 焦点分析）、情感趋势与拐点检测、主题热度排行、K-Means 主题聚类，结果可导出为 CSV / Excel / JSON。

## 快速启动

### 方式 A：直接运行打包好的 jar（推荐普通用户）

```bash
java -jar gkg-platform-1.0.0-shaded.jar
```

Windows 下双击 `run.bat` 也可以直接启动。

### 方式 B：在 IDE 中运行（开发者）

1. 用 IntelliJ IDEA 打开项目根目录（含 `pom.xml` 的那一层）
2. IDEA 右上角弹出「Load Maven Project」→ 点击，等待依赖下载完成
3. 打开 `src/main/java/edu/gkg/App.java`，点击 `main` 左侧绿色三角运行

> 默认以 **Mock 模式**启动（无需真实数据库，按钮点击后全部返回模拟数据，方便演示）。
> 切换真实数据模式：`java -Dmock=false -jar gkg-platform-1.0.0-shaded.jar`

## 功能使用说明

启动后窗口分为四个标签页：**数据管理 / 查询检索 / 挖掘分析 / 关于**。

---

### 1 数据管理

#### 1.1 导入 GKG 数据

1. 切到「**数据管理**」标签页
2. 把 GKG CSV 文件或整个目录**拖入中央虚线框**，或点击「选择文件 / 文件夹」按钮选择
3. 点击「**▶ 开始导入**」
4. 进度条实时推进，显示当前文件名和已处理行数
5. 完成后右侧三张统计卡显示「成功 / 跳过 / 失败」条数，底部历史表追加一行记录

> 支持格式：`.csv`、`.tsv`、`.gkg`，以及包含上述文件的 `.zip`（后续版本）。
> 跳过 = 字段不完整或格式异常，正常，不影响有效数据。

#### 1.2 数据清理

点击「**数据清理**」→ 确认弹窗 → 系统扫描并删除 V2Tone 缺失、日期非法等无效行，弹窗显示删除条数。

#### 1.3 停止导入

点击右上角「**停止导入**」，后台任务立即取消，进度条归零。

#### 1.4 导出结果

点击「**结果导出**」→ 在文件选择框中填写文件名（`.csv`、`.xlsx`、`.json` 均可）→ 保存。系统根据扩展名自动选择格式。

---

### 2 查询检索

#### 2.1 组合查询

1. 切到「**查询检索**」→ 子页「**组合查询**」
2. 填写任意组合条件：

   | 字段 | 示例 | 说明 |
   |---|---|---|
   | 起始日期 | `2024-01-15` | 格式 yyyy-MM-dd，留空不限 |
   | 结束日期 | `2024-01-15` | 同上 |
   | 主题代码 | `SANCTIONS` | GDELT 主题标签，大写 |
   | 人物名 | `Biden` | 英文，支持前缀匹配 |
   | 组织名 | `United Nations` | 同上 |
   | 地点名 | `Ukraine` | 同上 |

3. 点击「**搜索**」→ 下方表格显示匹配记录（每页 50 条）
4. 点击「**下一页 »**」/ 「**« 上一页**」翻页
5. 点击「**导出结果**」保存当前页
6. 点击「**重置**」清空所有条件

#### 2.2 人物档案

1. 子页切到「**人物档案**」
2. 在搜索框输入人物姓名（如 `Elon Musk`）→ 点击「**查询**」
3. 页面显示：
   - 四张统计卡：新闻总量 / 平均情感得分 / 关联主题数 / 正向报道比例
   - 「关联组织 TOP10」横向柱状图
   - 「关联人物 TOP10」横向柱状图
   - 12 个月新闻量折线图

#### 2.3 组织档案

操作与人物档案完全相同，子页切到「**组织档案**」，输入组织名（如 `NATO`、`SpaceX`）。

#### 2.4 主题追踪

1. 子页切到「**主题追踪**」
2. 填入主题代码（如 `SANCTIONS`）、起止日期
3. 点击「**绘制趋势**」
4. 折线图显示该主题在日期范围内每天的新闻频次

> 常用主题代码参考：`SANCTIONS`（制裁）、`PROTEST`（抗议）、`ELECTION`（选举）、`CLIMATE_CHANGE`（气候变化）、`CYBER_ATTACK`（网络攻击）

---

### 3 挖掘分析

切到「**挖掘分析**」标签页。左侧是控制面板，右侧是结果区（图形/表格）。

#### 3.1 F-12 共现网络构建

- 点击「**构建 / 刷新**」
- 系统扫描全库，统计所有人物/组织在同一篇新闻中共同出现的次数，写入共现表
- 完成后弹窗提示，右侧自动切到共现网络图（此时节点大小相同，点击 PageRank 后才按权重区分）

#### 3.2 F-13 PageRank 焦点人物 ⭐

1. 「F-13 PageRank ⭐」区域，拖动「**Top-N**」滑块选择展示数量（默认 50，最多 200）
2. 点击「**运行 PageRank**」
3. 右侧网络图：**节点越大 = PageRank 越高 = 新闻焦点人物**；边越粗 = 共现次数越多
4. 鼠标悬浮节点显示「姓名 / PageRank 值 / 度数」
5. 左键拖拽单个节点调整布局；空白处拖拽平移画布；滚轮缩放
6. 右侧同时切出「PageRank 焦点节点 Top-N」表格，可对照数值排名

> PageRank 算法原理（答辩要讲）：幂迭代法，每轮把自身得分按边权分配给邻居，反复迭代至收敛（max 差 < 1e-6）。节点被越多高分节点引用，自身分越高。

#### 3.3 F-14 主题热度排行

1. 选择时间粒度（**按日 / 按周 / 按月**）
2. 选择时间范围（**最近 7 天 / 30 天 / 6 个月**）
3. 点击「**运行热度分析**」
4. 右侧上方：主题热度排行表（主题代码 / 时间桶 / 频次）
5. 右侧下方：颜色渐变热力图，颜色越深频次越高

#### 3.4 F-15 K-Means 主题聚类

1. 在「**k 值**」输入框填入聚类数量（如 `5`，范围 2–20）
2. 点击「**运行聚类**」
3. 右侧表格显示每个簇的 ID、关键词列表、包含记录数

> K-Means 算法（答辩要讲）：将所有主题按出现模式映射到高维向量，随机初始化 k 个中心，反复把每个点分配到最近中心、然后更新中心坐标，直到收敛。

#### 3.5 F-16 情感趋势与拐点检测 ⭐

1. 「F-16 情感趋势 ⭐」区域，选择实体类型（**人物 / 组织 / 主题**）
2. 在名称框输入实体名（如 `Joe Biden`）
3. 点击「**运行分析**」
4. 右侧三联仪表盘：
   - **左：DialPlot 指针表** —— 指针指向该实体 V2Tone 总体平均情感（-10 到 +10）
   - **右：雷达图** —— 六轴：均值 / 正向强度 / 负向强度 / 波动性 / 拐点数 / 峰值
   - **下：情感趋势折线** —— 每日平均情感曲线；红色箭头 ↘ 标记拐点位置

> 拐点检测原理（答辩要讲）：滑动窗口（W=3），对每个时间点比较前 W 天均值和后 W 天均值，若符号相反且差的绝对值 ≥ 1.5，则判定为拐点。

## 常见问题

**Q：启动后界面中文显示为方块/乱码？**
在 JVM 参数里加 `-Dfile.encoding=UTF-8`：
```bash
java -Dfile.encoding=UTF-8 -jar gkg-platform-1.0.0-shaded.jar
```

**Q：图表里中文字体显示为方块？**
系统需要安装「微软雅黑」字体。Windows 默认已安装；Linux 执行：
```bash
sudo apt install fonts-wqy-microhei
```

**Q：导入很慢，几百条/秒？**
数据库默认开启同步写入保证安全。可在 `config.properties` 里加：
```
sqlite.pragma.synchronous=NORMAL
sqlite.pragma.journal_mode=WAL
```
一般能提速 5–10 倍。

**Q：点「运行 PageRank」提示「共现表为空」？**
需要先点「构建 / 刷新」生成共现表，再点 PageRank。

**Q：K-Means 一直转不停？**
k 值设太大（如 k=20 但数据只有几百条）可能收敛慢。先用 k=3 到 k=5 试验。

**Q：控制台打印 `Log4j2 could not find a logging implementation` 怎么处理？**
是 Apache POI 的日志警告，不影响任何功能，忽略即可。若想消除，在 `pom.xml` 加一行依赖：
```xml
<dependency>
    <groupId>org.apache.logging.log4j</groupId>
    <artifactId>log4j-to-slf4j</artifactId>
    <version>2.23.1</version>
</dependency>
```
