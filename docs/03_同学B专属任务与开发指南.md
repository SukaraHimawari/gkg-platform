## 一、核心职责定位

**一句话**：你是项目的"地基与发动机"——独立完成项目基础设施（Maven、SQLite、连接池）、所有实体与 DAO、GKG TSV 解析与入库、三个挖掘算法（**F-12 共现网络构建 / F-14 主题热度排行 / F-15 K-Means 聚类**），并负责 `AnalysisServiceImpl` 的总装（把 A 写的 PageRank、SentimentTrend 算法类一起串起来）。你不写 Swing，但你**必须按时把接口空实现交给 A**，否则 A 编译不过、UI 进度被卡。

**核心收益**：
- 学到 **数据工程**：复杂半结构化 TSV 解析、JDBC 批量入库、SQLite 性能调优
- 学到 **文本挖掘**：F-15 K-Means 聚类（TF-IDF + Weka）
- 学到 **图数据建模**：F-12 共现网络从原始记录到边表的构建过程
- 答辩时你能讲清"K-Means 怎么选 k""共现网络怎么从一条新闻拆成边"

### 模块 B6：F-12 共现网络构建（W4）⭐

> A 的 PageRank（F-13）会直接读你写好的 `cooccurrence` 表，**你必须先于 W5 把这表填稳定**。

- [ ] `algorithm/CooccurrenceBuilder.java`
  - 流式扫描全表 `gkg_record`
  - 对每条新闻读出关联人物集合 + 关联组织集合
  - **人物-人物**两两组合 → 累加边权（用 `Map<Pair, Integer>`）
  - **人物-组织**两两组合 → 同上
  - 写入 `cooccurrence` 表（`truncate` 后 `insertBatch`）
  - 单新闻人物数 > 20 时仅取出现频次最高的前 20，避免组合爆炸（`C(20,2)=190` 已够）
- [ ] 单测：`CooccurrenceBuilderTest` 3 行假数据 → 验证边权
- [ ] 把它接进 `AnalysisServiceImpl.rebuildCooccurrence()`（W6 装配时统一做）

### 模块 B7：F-14 主题热度排行（W5）

- [ ] `algorithm/ThemeRanker.java`
  - 输入：`Granularity{DAY,WEEK,MONTH}` + 日期范围 + topN
  - 输出：`List<ThemeHeat(code, period, count)>`
  - SQL：`SELECT t.code, strftime(...) AS period, COUNT(*) AS c FROM record_theme rt JOIN theme t ON ... WHERE publish_date BETWEEN ? AND ? GROUP BY t.code, period ORDER BY c DESC LIMIT ?`
  - 注意 SQLite 的 `strftime('%Y-%m', publish_date)` 写法

### 模块 B8：F-15 K-Means 主题聚类（W5~W6）⭐ 学习重点

- [ ] `algorithm/KMeansClusterer.java`
  - 输入：`k`、`maxIter`
  - 输出：`List<Cluster(clusterId, topKeywords, size)>`
  - 步骤：
    1. SQL 把每条新闻的所有 V2Themes 拼成一个空格分隔字符串作为"文档"
    2. Weka `Instances` + `StringToWordVector` 滤波器（TF-IDF）
    3. `SimpleKMeans` 设置 k、maxIter（≤ 50）
    4. 对每个簇：统计簇内所有文档高频词 TOP-10 作为 `topKeywords`
    5. 返回每簇的样本数与关键词
  - 数据量保护：文档数 > 1 万先 `Random` 抽样 1 万再聚类
  - 提示：Weka 的 `Filter.useFilter` 与 `SimpleKMeans.buildClusterer` 是关键 API

### 模块 B9：AnalysisService 总装（W6）

> ⭐ 这是和 A 的关键耦合点：你负责装配，**调用 A 提交的 `PageRankRunner` 与 `SentimentTrend`**。

- [ ] `service/impl/AnalysisServiceImpl.java`：
  ```java
  public class AnalysisServiceImpl implements AnalysisService {
      private final CooccurrenceDao cooccurDao;
      private final GkgRecordDao recordDao;
      // ...

      @Override public void rebuildCooccurrence() {
          new CooccurrenceBuilder(...).buildAndStore();   // 我的
      }
      @Override public List<FocusNode> topFocusPersons(int topN) {
          return new PageRankRunner(cooccurDao).topN(topN); // ⭐ A 的
      }
      @Override public List<ThemeHeat> themeHeatRank(Granularity g, LocalDate f, LocalDate t, int n) {
          return new ThemeRanker(...).rank(g, f, t, n);    // 我的
      }
      @Override public List<Cluster> clusterByKMeans(int k, int maxIter) {
          return new KMeansClusterer(...).cluster(k, maxIter); // 我的
      }
      @Override public SentimentSeries sentimentTrend(EntityRef ref, LocalDate f, LocalDate t) {
          return new SentimentTrend(...).compute(ref, f, t);   // ⭐ A 的
      }
  }
  ```
- [ ] **结果缓存**：用 `ConcurrentHashMap<CacheKey, Object>` 给 `topFocusPersons` / `themeHeatRank` 加内存缓存（key 是入参组合，TTL 10min）

### 模块 B10：CLI 自测入口（不依赖 A 的 UI）

```java
public class AppCli {
    public static void main(String[] args) throws Exception {
        DbHelper.init();
        switch (args[0]) {
            case "import" -> new ImportServiceImpl().importFile(new File(args[1]),
                (p, m) -> System.out.printf("[%3d%%] %s%n", p, m));
            case "cooccur" -> new AnalysisServiceImpl(...).rebuildCooccurrence();
            case "heat" -> new ThemeRanker(...).rank(Granularity.MONTH,
                LocalDate.parse(args[1]), LocalDate.parse(args[2]), 20)
                .forEach(System.out::println);
            case "kmeans" -> new KMeansClusterer(...).cluster(Integer.parseInt(args[1]), 50)
                .forEach(System.out::println);
        }
    }
}
```
